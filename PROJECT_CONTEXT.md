## 1. What the project is

**AI Buddy** (called **Placement Prep** in the research paper) is a MERN web application that helps engineering students prepare for campus placements. Everything is built around one learner profile:

- **Learning roadmap** generated by Google Gemini from four onboarding inputs (subject, goal, level, daily time).
- **Adaptive roadmap**: quiz scores are saved per topic; weak topics (< 60%) trigger a revision offer, and the learner can ask for changes in plain words. Completed topics are kept; the rest is regenerated.
- **Progress tracker** with a donut chart (topic status) and bar chart (completion per roadmap).
- **AI quizzes** (5 MCQs per topic, scored on the server).
- **Study planner** (day-by-day plan with weekly milestones).
- **Predict My Interview**: resume upload (PDF/DOCX, optional LinkedIn PDF) → structured profile → questions for a company and role in four groups (technical, project-based, behavioral, cultural fit).
- **AI Buddy chatbot** for doubt solving, available on every page and from each roadmap topic; it knows the learner's roadmaps, current topic and weak topics.

## 4. Running locally

1. Root `.env` needs these keys (values are private — never commit them): `PORT`, `MONGODB_URI`, `CORS_ORIGIN`, `ACCESS_TOKEN_SECRET`, `ACCESS_TOKEN_EXPIRY`, `REFRESH_TOKEN_SECRET`, `REFRESH_TOKEN_EXPIRY`, `GEMINI_API_KEY`.
2. Install: `npm install` in the root and in `frontend/`.
3. Start the API: `npm run dev` (root) → http://localhost:4000
4. Start the client: `npm --prefix frontend run dev` → http://localhost:5173
5. Forgot a password? `node scripts/reset-password.js <email> <newPassword>`

## 5. API reference

All routes except signup, login and refresh-token require the JWT cookie. Roadmap/topic routes also check ownership.

| Area | Routes |
| --- | --- |
| Users `/api/users` | POST `/signup`, `/login`, `/logout`, `/refresh-token` · GET `/me` |
| Roadmap `/api/roadmap` | POST `/generate` · GET `/me` · GET/DELETE `/:roadmapId` · **POST `/:roadmapId/adapt`** `{ instruction? }` |
| Progress `/api/progress` | POST `/complete` `{ topicId }` · GET `/roadmap/:roadmapId` · GET `/stats` |
| Quiz `/api/quiz` | POST `/:topicId/generate` · GET `/:topicId` · POST `/:topicId/submit` `{ answers[] }` (saves `quizScore` on the topic) |
| Planner `/api/planner` | POST `/generate/:roadmapId` · GET `/:roadmapId` · PATCH `/:roadmapId/task/:taskId/toggle` |
| Interview `/api/interview` | POST `/profile/upload` (fields `resume`, `linkedin`) · GET `/profile` · POST `/generate` · GET `/me` · GET `/:id` |
| Chat `/api/chat` | **POST `/`** `{ messages: [{ role, content }], topicId? }` → `{ reply }` |

## 6. Data model (actual schemas)

- **User**: name, email (unique), password (bcrypt), refreshToken
- **Roadmap**: userId, subject, goal, level, timeAvailable, **adaptations[]** `{ instruction, summary, at }`
- **Topic**: roadmapId, title, order, status (`locked` | `current` | `completed`), resources[], **quizScore**
- **Progress**: userId, topicId, completed, streak, completedAt
- **Quiz**: topicId, questions[] (one quiz per topic)
- **StudyPlanner**: roadmapId, dailyTasks[], weeklyMilestones[], estimatedCompletionDate (one per roadmap)
- **CandidateProfile**: userId, resumeText, linkedinText, parsedSkills/Projects/Education/Experience (one per user)
- **InterviewPrep**: userId, company, role, jobDescription, generatedQuestions, createdAt

Relationships: User 1–N Roadmap, User 1–1 CandidateProfile, User 1–N InterviewPrep, User 1–N Progress, Roadmap 1–N Topic, Roadmap 1–1 StudyPlanner, Topic 1–N Progress, Topic 1–1 Quiz.

## 7. Gemini integration (`src/utils/geminiclient.js`)

- `generateJsonFromPrompt` — JSON-mode generation. Tries a model priority list (`gemini-3.5-flash-lite` first, four fallbacks); moves to the next model immediately on overload/rate limit; if a reply is cut off by the token limit, retries once with double the budget.
- `generateJsonFast` — same, smaller budget/timeout (quizzes).
- `generateChatReply` — multi-turn plain-text replies with a system instruction (chatbot).

| Parameter | Value |
| --- | --- |
| Temperature (JSON / chat) | 0.3 / 0.6 |
| Max output tokens (roadmap, plans, profiles) | 8,192 (doubled once on truncation) |
| Max output tokens (quiz / chat) | 4,096 / 4,096 |
| Timeouts (JSON / quiz / chat) | 60 s / 30 s / 45 s |
| Weak-topic threshold | quiz score < 60% |
| Topics after adaptation | 3–10 requested, max 10 kept |
| Adaptation request | ≤ 300 characters |
| Chat history sent | last 16 messages, ≤ 2,000 chars each |
| Express JSON body limit | 64 KB |

## 8. Change log (work done in these sessions)

### Bugs fixed
1. **Login reload loop** — logged-out users saw "Initializing AI Buddy…" forever because the 401 handler did a full-page redirect to `/login`, which re-triggered the auth check. Fix: skip the redirect when already on `/login` or `/signup`. *(frontend/src/utils/api.js)*
2. **Roadmap generation slow and failing** — replies were capped at 1,024 tokens; newer Gemini models spend part of that on reasoning, so JSON was truncated and each request made ~10 failing calls with 3–6 s sleeps. Fix: 8,192-token budget, truncation-aware retry, no sleeping on overloaded models, per-call timeouts; roadmap prompt trimmed to 8–10 topics × 2–3 resources. Now ~15 s, first try. *(src/utils/geminiclient.js, src/controllers/roadmap.controller.js)*
3. **PDF resume upload crashed** ("pdfParse is not a function") — pdf-parse v2 replaced its function with a `PDFParse` class. Fix: use the class. *(src/utils/resumeParser.js)*
4. **Chat formatting** — single-asterisk italics and stray `###` headings now render cleanly. *(frontend/src/components/ChatWidget.jsx)*

### Features added
- **Progress charts** — donut (topic status) + bar chart (completion per roadmap), validated muted palette. *(frontend/src/components/ProgressCharts.jsx, pages/ProgressPage.jsx)*
- **Adaptive roadmap** — quiz score saved per topic; weak-topic banner; "Adapt roadmap" panel with quick chips; adaptation history with the latest summary shown. *(topic/roadmap models, quiz + roadmap controllers, roadmap routes, pages/RoadmapPage.jsx, index.css)*
- **AI Buddy chatbot** — floating chat on every page, "Ask" button per topic, learner-aware system prompt, safe React rendering (no raw HTML), history kept per user in localStorage. *(src/controllers/chat.controller.js, src/routes/chat.routes.js, src/app.js, frontend/src/components/ChatWidget.jsx, App.jsx, index.css)*
- **Password reset script** *(scripts/reset-password.js)*
- **Dev launch config** *(.claude/launch.json)*

## 10. Known issues and limitations

- No automated tests; evaluation so far is functional testing by the team.
- AI-generated resource links are not human-reviewed and can occasionally be wrong.
- Depends on Gemini availability and free-tier rate limits.
- Response times above are single observations, not averages.
- Deleting a roadmap does not yet delete its quizzes/planner.
- Mongoose warns that `new: true` in `findOneAndUpdate` is deprecated (use `returnDocument: 'after'`).
- Study plans are not regenerated after a roadmap adaptation.

## 12. Notes on plagiarism / AI detection

- Turnitin shows two separate numbers: **similarity** (matches to sources) and **AI writing** (likelihood text is AI-generated). They need different responses.
- High similarity on a reworded paper usually means an earlier version was already stored in Turnitin's repository; ask the guide to exclude that source and enable "Exclude bibliography".
- The AI-writing score cannot and should not be gamed. The paper includes an **AI-use acknowledgment**; keep it in line with the college's policy, and have team members write or rewrite sections in their own words.
